LeadSeed

Política de Privacidad

Última actualización: 17 de agosto de 2026

LeadSeed es una herramienta de productividad y gestión comercial que funciona, entre otros entornos, como extensión de Chrome con panel lateral. Permite gestionar contactos y leads, tareas, agenda, comunicaciones y funciones de colaboración. Esta Política explica qué información puede tratar LeadSeed, para qué se utiliza y con qué servicios puede compartirse cuando es necesario para prestar sus funciones.

Principio de uso limitado: LeadSeed utiliza los datos obtenidos mediante permisos de la extensión y APIs conectadas únicamente para proporcionar o mejorar funciones visibles solicitadas por el usuario. LeadSeed no vende datos personales, no los utiliza para publicidad personalizada, no los entrega a corredores de datos y no los utiliza para determinar solvencia o elegibilidad crediticia.

1. Información que puede tratar LeadSeed

Cuenta y autenticación. Podemos tratar correo electrónico, identificadores de cuenta, información básica de perfil entregada por el proveedor de autenticación y tokens de sesión necesarios para mantener al usuario autenticado.

Datos de contactos y leads. LeadSeed puede almacenar información que el usuario ingresa o importa, como nombre, teléfono, correo electrónico, empresa, notas, estados comerciales y otros campos relacionados con la gestión del contacto.

Tareas, agenda y contenido creado por el usuario. Podemos tratar tareas, notas, disponibilidad, citas, participantes, plantillas de mensajes, contenido de correos preparados para envío, conversaciones internas y contenido de colaboración creado dentro de LeadSeed.

Preferencias locales. La extensión puede guardar en el navegador preferencias de uso, configuración visual y otros ajustes necesarios para recordar el estado de la interfaz.

2. Cómo utilizamos la información

  • Autenticar al usuario y mantener su sesión.
  • Mostrar, organizar, actualizar, importar y exportar contactos y leads.
  • Gestionar tareas, agenda, disponibilidad, citas y recordatorios.
  • Preparar y enviar comunicaciones iniciadas por el usuario.
  • Sincronizar las funciones de Google autorizadas por el usuario.
  • Prestar funciones de chat, comunidad y colaboración disponibles dentro de LeadSeed.
  • Mantener la seguridad, continuidad y funcionamiento técnico del servicio.

3. Uso de Google Sign-In, Gmail y Google Calendar

Cuando el usuario conecta su cuenta de Google, LeadSeed puede recibir información básica de identidad, incluyendo el correo electrónico de la cuenta, junto con tokens OAuth y el alcance de permisos concedido. LeadSeed puede almacenar el token de acceso, token de actualización, permisos concedidos y fecha de expiración para mantener activa la integración autorizada.

Gmail. LeadSeed utiliza Gmail API para enviar mensajes que el usuario decide enviar desde la aplicación. La implementación revisada de LeadSeed utiliza el permiso de envío de Gmail y no requiere leer la bandeja de entrada ni el contenido de correos recibidos para esta funcionalidad.

Google Calendar. Cuando está autorizado, LeadSeed puede crear, modificar y eliminar eventos de calendario; añadir participantes; generar enlaces de Google Meet; y consultar información de disponibilidad mediante la función Free/Busy. Al crear una cita, el evento puede incluir información que el usuario haya asociado al lead, como nombre, teléfono, correo electrónico, empresa, notas y participantes.

Para sincronizar disponibilidad, LeadSeed puede consultar intervalos ocupados de Google Calendar y guardar bloques horarios necesarios para evitar dobles reservas. Esta función no necesita copiar el contenido completo de todos los eventos del calendario.

Google API Services User Data Policy.
The use of information received from Google Workspace scopes will adhere to the Google User Data Policy, including the Limited Use requirements.

LeadSeed no utiliza información obtenida a través de Google Workspace APIs para desarrollar, mejorar o entrenar modelos de inteligencia artificial o aprendizaje automático generalizados o no personalizados.

4. Servicios de terceros

LeadSeed puede utilizar proveedores externos únicamente cuando son necesarios para prestar las funciones solicitadas. Entre ellos pueden encontrarse:

  • Supabase: autenticación, base de datos, sincronización y funciones de backend.
  • Google: autenticación, Gmail API, Google Calendar API y servicios OAuth autorizados.
  • Resend: procesamiento y entrega de correos cuando el usuario utiliza un canal Resend.
  • EmailJS: proveedor de correo disponible como integración heredada cuando el usuario decide utilizarlo.
  • WhatsApp Web: LeadSeed puede abrir conversaciones o enlaces hacia WhatsApp Web para facilitar comunicaciones iniciadas por el usuario.

Estos proveedores reciben solamente la información necesaria para prestar la función correspondiente y están sujetos a sus propios términos y políticas de privacidad.

5. Credenciales de servicios de correo

Cuando un usuario configura credenciales de un canal de correo compatible, LeadSeed las procesa para habilitar dicho canal. La implementación de backend cifra las credenciales de canales compatibles antes de almacenarlas en la base de datos. Las credenciales no se utilizan para fines publicitarios ni se venden a terceros.

6. Seguridad

LeadSeed utiliza conexiones HTTPS/TLS para proteger la información durante su transmisión y aplica controles de autenticación y autorización para limitar el acceso a los datos del usuario. Ningún sistema puede garantizar seguridad absoluta, por lo que mantenemos medidas razonables orientadas a reducir accesos, usos o divulgaciones no autorizadas.

7. Conservación y eliminación

Los datos se conservan mientras sean necesarios para prestar LeadSeed, mientras la cuenta permanezca activa o hasta que el usuario elimine información disponible dentro de la aplicación. Los tokens OAuth de Google se conservan únicamente mientras sean necesarios para mantener la integración autorizada. El usuario también puede revocar el acceso de LeadSeed desde la configuración de seguridad de su Cuenta de Google.

Determinados registros técnicos o copias de seguridad pueden conservarse durante un período limitado cuando sea necesario por razones de seguridad, continuidad, prevención de fraude, resolución de incidencias u obligaciones legales.

8. Acceso humano a los datos

El personal o colaboradores de LeadSeed no acceden al contenido privado del usuario salvo cuando sea estrictamente necesario para prestar soporte solicitado por el usuario, investigar una incidencia de seguridad o abuso, cumplir una obligación legal, o realizar operaciones internas sobre datos agregados o anonimizados.

9. Venta, publicidad y otros usos prohibidos

LeadSeed no utiliza los datos obtenidos a través de la extensión o de Google Workspace APIs para:

  • vender o alquilar información personal;
  • publicidad personalizada o retargeting;
  • crear perfiles comerciales ajenos a la funcionalidad solicitada por el usuario;
  • determinar solvencia, crédito, seguros o elegibilidad financiera;
  • transferir datos a corredores de datos;
  • entrenar modelos generales de IA/ML.

10. Derechos y control del usuario

Según las funciones disponibles, el usuario puede acceder, corregir, exportar o eliminar información de contactos y otros registros que administra en LeadSeed. También puede revocar los permisos de Google desde su Cuenta de Google. Para consultas adicionales relacionadas con privacidad o eliminación de datos, el usuario puede utilizar el canal de soporte publicado en la ficha oficial de LeadSeed en Chrome Web Store.

11. Cambios a esta Política

Podemos actualizar esta Política cuando cambien las funciones de LeadSeed, los proveedores utilizados o los requisitos aplicables. La fecha de última actualización se mostrará al inicio de esta página. Si un cambio modifica de forma material el uso de datos de Google u otros datos sensibles, actualizaremos las divulgaciones correspondientes antes de utilizar la información para el nuevo propósito.

12. Contacto

Para consultas de privacidad, soporte o solicitudes relacionadas con datos personales, utiliza el correo o canal de soporte indicado en la ficha oficial de LeadSeed en Chrome Web Store. Antes del lanzamiento público general, esta sección podrá actualizarse para incluir un correo de privacidad dedicado.
